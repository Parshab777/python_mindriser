# Git and Git-hub

Git - VCS(Version Control System) , track the progress of the project, create the local repository which is used to track the changes.


Git-Hub - git based system, implement VCS (Version Control System) , store projects.

// initialize
git init


// add the files
git add file_name (add single file)
git add . (add multiple files)


// commit
git commit -m "meaning full message"

// change the name of the master branch
git branch -M main



// check all the existing branch
git branch


// create new branch
git branch new_branch_name

// change the branch
git checkout new_branch_name

// merge
git merge branches_name
